# End-to-End Network Security ETL ML Pipeline

## Project Overview
This project implements a complete, production-grade End-to-End (E2E) Machine Learning and ETL pipeline designed for network security classification and anomaly detection. The system automates the entire lifecycle of data processing, model training, tracking, and cloud-native deployment using modern MLOps principles.

## Objectives
* Automate the `ingestion`, `validation`, and `transformation` of network security data.
* Implement robust experiment tracking and model lineage using MLOps tooling.
* Establish a fully automated Continuous Integration and Continuous Deployment (CI/CD) pipeline via GitHub Actions and AWS EC2.
* Provide a high-performance web interface using FastAPI for real-time predictions and on-demand model training.

---

## Dataset Information
The pipeline ingests raw network security data (**PhisingData.csv**) and create connection sourced securely from a MongoDB database. The dataset contains various network traffic features utilized to classify secure versus malicious patterns.

**Dataset**: [phisingData.csv](https://github.com/user-attachments/files/31305648/phisingData.csv)

## Data Operation

### Data Ingestion
* Connects securely to MongoDB using TLS certificates and environment variables.
* Extracts raw records and divides data into appropriate training and testing splits for subsequent pipeline stages.

### Data Transformation
* Cleans raw inputs and handles missing attributes using imputation method.
* Applies **normalization**, **scaling**, and **feature engineering** to ensure compatibility with machine learning estimators.
* Persists preprocessor objects using serialization utilities (`dill`/`pickle`) for consistent inference-time transformations.

### Data Validation
* Validates schema structures, column types, and data drift parameters before allowing data to proceed to transformation and training phases.

### Model Training
* Trains classification models using engineered feature sets.
* Integrates experiment tracking via **DagsHub** to manage hyperparameters, artifacts, and training metrics.
* Serializes the final trained estimator into a reusable artifact package (`NetworkModel`).

---

## Hyperparameter Tuning
* Incorporates systematic tuning frameworks during the model training phase to optimize estimator performance metrics and ensure high predictive accuracy on network security data.

## Conclusion
This project successfully bridges the gap between raw data engineering and production deployment. By decoupling training routines from the FastAPI inference server and implementing automated containerized delivery via AWS ECR and EC2, the pipeline achieves high availability, scalability, and reproducibility.
